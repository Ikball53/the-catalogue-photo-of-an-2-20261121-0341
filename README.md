# Banknote Press — Catalogue Photo

A photorealistic catalogue photograph of an impossible gadget: a miniature desktop steam-iron machine flattening a crumpled banknote, with one crumpled banknote beside it as the single accessory. Running `main.py` copies the bundled `entry.png` to `/output/entry.png`.
